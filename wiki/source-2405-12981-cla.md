# Source: Reducing Transformer Key-Value Cache Size with Cross-Layer Attention（CLA）

Brandon*, Mishra*, Nrusimha, Panda, Ragan-Kelley（MIT CSAIL / MIT-IBM Watson AI Lab），arXiv:2405.12981v1，2024-05-21，Preprint（under review）。PDF：raw/2405.12981-cla.pdf。

## 摘要

论文提出 [[cross-layer-attention|Cross-Layer Attention（CLA）]]：只在层数子集（每组 $f$ 层的组首层）计算 K/V 投影，组内其余层删除 K/V 投影、复用同一份 KV 激活，KV cache 从每层一份压到 $\lceil L/f\rceil$ 份（§2.2、Figure 1–2）[^src-2405-12981-cla]。作者将论文定位为 MQA 的下一步：在 head 间共享（[[multi-query-attention|MQA]]/[[grouped-query-attention|GQA]]）之上再叠加层间共享，与三者正交可组合（Abstract、§2.2）[^src-2405-12981-cla]。

## 机制与关键结果

- cache 每 token 字节数 $4\,n_{kv}\,d_{head}\lceil L/f\rceil$（16-bit），相对 MQA 再缩 $f$ 倍（§2.2、Table 1）[^src-2405-12981-cla]。
- 1B/3B（SlimPajama，30B/100B token）从零训练：MQA-CLA2 对同 $d_{head}$ 的 MQA 以 2× 缩缓存、ppl 至多退 0.04 点（Table 3），对同内存的小 head MQA 改善 0.21–0.48 点（Table 1）；3B 第一组 CLA2 以一半缓存同时低于两个基线（val ppl 9.34 对 9.52/9.48，Table 5）[^src-2405-12981-cla]。
- 消融：$f=2$ 优于 $f=3,4$（同内存下 13.60/13.77/13.95，Table 1）；均匀相邻配对优于 KeepEnds/DenseFront/DenseBack 三种非均匀模式（13.60 对 13.62/13.75/14.03，且非均匀更费内存，Table 1）；CLA 偏好更高学习率（2.25×10⁻³ 对 1.5×10⁻³，Table 3/5）[^src-2405-12981-cla]。
- 系统性质：省 cache 容量不省每步带宽（共享 KV 逐层仍要重读），TP 兼容、PP 需同组层同 stage，参数与 FLOPs 略降（§2.3）[^src-2405-12981-cla]。

## 边界

无端到端推理效率实测（§4 Future work）；全部从零训练、无 checkpoint 转换路径；规模止于 3B；单 seed；下游七任务无一致胜负；与量化/驱逐的正交性未做组合实验（§4、§5.1）[^src-2405-12981-cla]。
