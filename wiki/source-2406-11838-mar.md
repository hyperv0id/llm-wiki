# MAR — Autoregressive Image Generation without Vector Quantization

**作者:** Tianhong Li、Yonglong Tian（MIT）、He Li（Google DeepMind）、Mingyang Deng（清华大学）、Kaiming He（MIT）
**发表:** arXiv:2406.11838v3（2024-11-01，cs.CV）；PDF 内核实为 NeurIPS 2024
**raw:** `raw/2406.11838-mar.pdf`（arXiv v3 下载）；代码 https://github.com/LTH14/mar

## 核心论点

1. **VQ 不是自回归的必要条件**：论文将自回归的本质归结为"基于已知 token 预测下一个 token"，它与取值离散或连续无关；真正必需的是 per-token 概率分布的损失函数与采样器。离散 token 空间隐含 categorical 分布（cross-entropy + 温度采样），这只是最方便的一种实现，不是概念前提[^src-2406-11838-mar]。
2. **Diffusion Loss**：自回归模型在每个位置输出条件向量 z，作为小型去噪 MLP 的条件，用扩散过程（ε-prediction、cosine schedule、iDDPM 范式）建模 p(x|z)。该 MLP 与自回归网络联合训练、梯度回传到 z，作者将其定位为一种参数化损失函数（类比对抗损失、感知损失）[^src-2406-11838-mar]。详见 [[diffusion-loss]]。
3. **广义自回归框架**：论文证明双向注意力同样可以执行自回归（MAE 式 encoder/decoder + mask token 位置嵌入），并把 raster-order AR、random-order AR、masked generative 模型（MaskGIT/MAGE 一系）统一为"next set-of-tokens prediction"的 [[masked-autoregressive-model|MAR]] 变体[^src-2406-11838-mar]。
4. **与相关工作划界**：GIVT 用固定混合数的高斯混合模型表达连续 token 分布，预设混合数限制了可表达的分布类型；本方法用扩散过程表达任意分布。DiffMAE/DARL 将扩散解码用于表示学习而非生成；Diffusion Policy 在概念上相关（动作分布 = 去噪过程）[^src-2406-11838-mar]。

## 实验结果（作者报告）

ImageNet 256×256、MAR-L（~400M）400 epochs、LDM 公开 tokenizer（KL-16 连续 / VQ-16 离散）：

- Diffusion Loss 在全部 AR/MAR 变体上一致优于 cross-entropy；默认 MAR 设置下 FID 从 8.79 降到 3.50（w/o CFG，相对约 50–60%），w/ CFG 3.69 → 1.98（Table 1）。
- 同损失下 tokenizer 对比：VQ-16 重建 rFID 5.87 vs KL-16 1.43，对应生成 FID 7.82 vs 3.50（w/o CFG）；即使 VQ tokenizer，取量化前的连续潜变量也能用 Diffusion Loss（7.82 vs cross-entropy 8.79）——差距主要来自量化损失而非损失函数（Table 2）。
- 去噪 MLP 极小（默认 3 块、宽 1024、21M，约 MAR-L 5% 参数），采样占推理时间约 10%；FID < 2.0 时生成速度 < 0.3 秒/图（Table 3、Figure 6，A100、batch 256，对比 DiT-XL）。
- 系统对比（800 epochs、256 自回归步）：MAR-B/L/H（208M/479M/943M）w/ CFG FID 2.31/1.78/1.55，最佳 1.55 对照 DiT-XL/2 2.27、MDTv2-XL/2 1.58、GIVT 3.35；w/o CFG 报告 2.35（Table 4、正文）。ImageNet 512×512 MAR-L w/ CFG 1.73（Table 6）。
- 消融：MAR + L2 损失 FID > 100（连续 token 下确定性回归无法生成多样性）；100 步扩散采样足够；温度 τ 显著影响 FID/IS；完全随机顺序与 MAGE 式置信度选位结果相当（8.79 vs 8.72，cross-entropy 口径），但随机顺序使训练/推理的顺序分布一致并支持 token 级温度采样（Table 5、Figure 4/5、D.3）。
- 训练成本：16 台服务器 × 8 V100 上 MAR-L 400 epochs 约 2.6 天，同设置 DiT-XL/2 4.6 天、LDM-4 9.5 天（附录 B）。

## 范围与局限

- 附录 A 自述三点局限：生成图像仍有可见伪影（Figure 8，与 ImageNet 学术训练设定下的既有方法类似）；系统依赖预训练 tokenizer 的质量，训练更好 tokenizer 超出本文范围；计算资源有限，主要在 ImageNet 上验证，更多样场景的可扩展性待验证。
- 附录 D.1 演示了直接建模 RGB 像素空间（4×4 像素/token，ImageNet 64×64，FID 2.93），但像素空间计算代价显著更高，更高分辨率留作未来工作。
