# VAR — Visual Autoregressive Modeling

**作者:** Keyu Tian（北京大学 / ByteDance）、Yi Jiang（ByteDance，project lead）、Zehuan Yuan（ByteDance，通讯）、Bingyue Peng（ByteDance）、Liwei Wang（北京大学，通讯）
**发表:** arXiv:2404.02905v2（2024-06-10，cs.CV）；PDF 内标注 "Preprint. Under review."，接收 venue 未在 PDF 内核实
**raw:** `raw/2404.02905-var.pdf`（arXiv v2 下载）；代码 https://github.com/FoundationVision/VAR

## 核心论点

1. **Next-scale prediction**：把图像自回归的单位从单个 token 换成整个 token map——图像被多尺度 VQVAE 编码为 K 个由粗到细的 token map $(r_1,\dots,r_K)$，似然分解为 $p(r_1,\dots,r_K)=\prod_k p(r_k|r_1,\dots,r_{k-1})$；每个自回归步并行生成第 k 个尺度的全部 $h_k\times w_k$ 个 token，尺度间自回归、尺度内并行[^src-2404-02905-var]。详见 [[next-scale-prediction]]。
2. **对 raster-scan AR 的四点批评**：数学前提违反（VQVAE 特征图的 token 双向相关，违反单向依赖假设，附录 A 给出 attention 热图证据）、无法做需要双向推理的零样本任务（如给下半图预测上半图）、flatten 破坏空间局部性、低效（O(n²) 步、O(n⁶) 计算；VAR 为 O(log n) 步、O(n⁴) 计算，附录 B 证明）[^src-2404-02905-var]。
3. **Scaling laws 与零样本泛化**：论文将 VAR 定位为在视觉上初步复现 LLM 的两个标志性质——按 LLM scaling law 协议训练 12 个模型（18.5M–2B），test loss 与 token 错误率随参数量 N 和最优训练算力 C_min 呈幂律（如 $L_{last}=(2.0N)^{-0.23}$、$L_{avg}=(2.5N)^{-0.20}$，Pearson 系数约 −0.998，关系跨 C_min 六个数量级成立）；零样本 in-painting / out-painting / class-conditional editing 无需改架构或微调[^src-2404-02905-var]。

## 实验结果（作者报告）

ImageNet 256×256 类条件生成（Table 1）：

- VAR-d16/20/24/30（310M/600M/1.0B/2.0B，10 步生成）：FID 3.30/2.57/2.09/1.92，IS 274.4/302.6/312.9/323.1；加 rejection sampling 的 VAR-d30-re 达 FID 1.73、IS 350.2（验证集参考下界 1.78）。
- 论文自称这是 GPT-style AR 模型首次在图像生成上超越扩散 Transformer：DiT-XL/2 为 FID 2.27（推理耗时 45×）、L-DiT-3B 2.10、L-DiT-7B 2.28、GigaGAN 3.45、MaskGIT 6.18、VQGAN 15.78。
- 推理速度：相比 VQGAN / ViT-VQGAN 约 20× 加速；数据效率：350 epochs vs DiT-XL/2 的 1400 epochs；扩展性：DiT 在 675M 后增益边际或为负，VAR 持续改善。
- ImageNet 512×512（Table 2）：VAR-d36-s（资源共享 AdaLN）FID 2.63、IS 303.2（时间基准 1×），对比 DiT-XL/2 3.04（81×）。
- 消融（Table 3）：同设置下 AR（VQGAN 227M）FID 18.65 → 换成 VAR-d16（207M，无 AdaLN/Top-k/CFG）5.22，推理成本仅 0.013×；+AdaLN 4.95、+Top-k 4.64、+CFG(2.0) 3.60、+q/k 归一化 3.30、放大到 2.0B 1.73。

## 方法要点

- **Tokenizer**：沿用 VQGAN 架构与训练（OpenImages、L1/L2 + LPIPS + StyleGAN 判别器复合损失、16× 下采样），改为多尺度残差量化：特征图逐级插值到 $h_k\times w_k$ 后量化、查找、上采样、经第 k 个卷积 $\phi_k$ 后从特征图残差中扣除；所有尺度共享码本（V=4096），额外参数仅 K 个卷积（0.03M）[^src-2404-02905-var]。
- **Transformer**：GPT-2 式 decoder-only + AdaLN（class embedding 兼作 start token 与条件），q/k 单位归一化稳定训练；显式不用 RoPE/SwiGLU/RMSNorm；形状规则 w=64d、heads=d，参数量 N(d)=73728d³[^src-2404-02905-var]。

## 范围与局限

- 论文自述聚焦学习范式、刻意保持 VQVAE 与 baseline 一致，tokenizer 改进（FSQ 等）视为正交方向；text-prompt 生成在进行中；视频生成（3D next-scale）为展望[^src-2404-02905-var]。
- 与 [[masked-autoregressive-model|MAR]]（arXiv:2406.11838，NeurIPS 2024）同期不同团队：VAR 保留离散 VQ token + 逐尺度层级顺序，MAR 改用连续 token + 随机顺序 token 子集；两文互不引用。
