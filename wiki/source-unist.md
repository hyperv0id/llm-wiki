# UniST: A Prompt-Empowered Universal Model for Urban Spatio-Temporal Prediction

UniST is the first one-for-all spatio-temporal foundation model for urban prediction, published at KDD 2024 by Yuan Yuan, Jingtao Ding, Jie Feng, Depeng Jin, and Yong Li (Tsinghua University, Department of Electronic Engineering)[^src-unist]. It enables a single model to handle 20+ spatio-temporal datasets across multiple cities and domains (taxi flow, crowd, traffic speed, cellular network, bike demand) without per-dataset architectural modifications[^src-unist].

## Core Problem

Existing spatio-temporal prediction methods are "one dataset, one model" — a model trained on TaxiBJ (32×32 grid) cannot be applied to CellularNJ (16×20 grid) due to incompatible input shapes. Moreover, direct joint training of existing models on multiple datasets (e.g., PatchTST one-for-all) produces /worse/ results than single-dataset training, because different cities' spatio-temporal data lack a shared "vocabulary" analogous to language[^src-unist].

## Key Innovations

**1. Spatio-Temporal Patching.** A trainable 3D convolutional layer with kernel size = stride = patch size unifies data of arbitrary $(T, H, W)$ dimensions into fixed-length token sequences via channel-independent splitting and patching: $\mathbf{E}_x = \text{Conv3D}_{(l,h,w)}(X)$. This preserves spatial topology rather than naively reshaping[^src-unist].

**2. Four Complementary Masking Strategies.** During MAE-style pre-training, UniST randomly selects from four masking strategies per mini-batch: random masking (fine-grained relations), tube masking (full temporal nullification of a spatial unit, simulating sensor failure), block masking (contiguous spatial block missing, hardest for spatial extrapolation), and temporal masking (future steps masked, enforcing causal modeling). Ablation shows each strategy is indispensable — removing temporal masking hurts prediction most, removing block masking hurts spatial extrapolation most[^src-unist].

**3. Knowledge-Guided Prompt Learning.** Instead of fine-tuning model parameters, UniST freezes the pre-trained encoder-decoder backbone and injects adaptive prompts into the input token space. Prompts are generated by querying two learnable memory pools ($KM_s$ spatial, $KM_t$ temporal) with four domain-knowledge features extracted from input: spatial closeness (3×3 CNN), spatial hierarchy (5×5/7×7/9×9 multi-scale CNN), temporal closeness (attention over recent $M$ steps), and temporal periodicity (attention over $N$ previous days' corresponding slots). The attention-weighted memory values become adaptive prompts $P_{sc}, P_{sh}, P_{tc}, P_{tp}$[^src-unist].

**4. Memory-Based Adaptive Generalization.** The key insight is that different data samples generate /different/ prompts — the same city's train/test sets produce similar prompt attention patterns, while different cities' datasets produce distinct patterns. t-SNE visualization shows memory pool embeddings diverging from uniform initialization to specialized patterns during training, each "remembering" a distinct spatio-temporal mode[^src-unist].

## Experimental Results

UniST achieves **universal superiority** across all datasets in short-term (6→6 steps) and long-term (64→64 steps) prediction. Key numbers: TaxiBJ RMSE 26.84 vs best baseline STID 27.36; Crowd RMSE 3.00 vs STID 3.85 (↓22.1%); Cellular RMSE 14.29 vs PromptST 15.74 (↓9.2%)[^src-unist]. In **few-shot prediction** (1% training data), UniST's advantage is most pronounced — RMSE 13.95 on Crowd vs PatchTST's 14.49. In **zero-shot** (no target data), UniST RMSE 14.67 on Crowd surpasses ACFM's 1%-shot result (21.17) and PredRNN's 1%-shot (24.90)[^src-unist].

Model size: 6.71M parameters, 2,875MB memory. Training: 1.4 min/epoch on 20+ datasets. Sine-cosine position encoding significantly outperforms learnable PE under noise perturbation — a critical design choice for generalization[^src-unist].

## Limitations

1. **Grid-only**: UniST supports only grid-based Euclidean data, not graph-based (road network) or sequence-based (sensor) formats[^src-unist].
2. **Diminishing scaling returns**: Performance saturates going from 2M to 30M parameters, unlike language/vision models — attributed to lower information diversity in spatio-temporal data[^src-unist].
3. **Simple knowledge extraction**: CNN + attention for domain knowledge is rudimentary; Fourier-based or more sophisticated methods could improve[^src-unist].
4. **Zero-shot gap**: Zero-shot RMSE 14.67 vs full fine-tuning 13.41 on Crowd — ~9% gap remains[^src-unist].

## Significance

UniST is KDD 2024's seminal paper establishing the one-for-all paradigm in urban spatio-temporal prediction. It demonstrated that a non-LLM route — pure spatio-temporal data with MAE pre-training and prompt learning — can achieve universal generalization across cities and domains. The memory-pool prompt architecture has become a reusable template for subsequent ST foundation models (UrbanDiT, etc.)[^src-unist]. GitHub repository: tsinghua-fib-lab/UniST.
