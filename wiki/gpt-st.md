# GPT-ST

**GPT-ST** (Generative Pre-Training for Spatio-Temporal Prediction) is a plug-and-play spatio-temporal pre-training framework that enhances existing ST prediction models without modifying their architectures[^src-gpt-st]. Published at NeurIPS 2023 by Li, Xia, Xu & Huang, it is the first general-purpose pre-training framework for spatio-temporal graph neural networks that works across 13 downstream baselines on 4 datasets with universal performance improvement[^src-gpt-st].

## Core Idea

GPT-ST is not a standalone prediction model. It is a pre-training engine built on the masked autoencoding (MAE) paradigm: given spatio-temporal data X ∈ R^{R×T×F}, it masks 25% of the signals and trains an encoder-decoder to reconstruct them[^src-gpt-st]. After pre-training, the encoder's output representation ζ is fused into any downstream STGNN's input via a learnable gating mechanism without changing the downstream architecture[^src-gpt-st].

The three architectural innovations:

### 1. Customized Temporal Pattern Encoding

Time-dynamic and region-specific parameters generated by a parameter learner, not directly learned[^src-gpt-st]:

- **Temporal hypergraph**: H_r ∈ R^{H_T×T} (H_T=8 hyperedges) for each region r, connecting time slots through multi-way relations — some hyperedges learn "weekend" patterns, others "morning peak"[^src-gpt-st]
- **Parameter generation**: W_t = d_t^T W̄, b_t = d_t^T b̄ — time-specific weights generated from time-of-day and day-of-week features via MLP, rather than shared across all time steps[^src-gpt-st]
- **Region customization**: H_r = c_r^T H̄ — each region has its own hypergraph structure while sharing a base H̄[^src-gpt-st]

Propagation: Γ_t = σ(Ē_t · W_t + b_t + E_t), where Ē_r = σ(H_r^T · σ(H_r · E_r))[^src-gpt-st].

### 2. Hierarchical Spatial Pattern Encoding

Two-level structure operating on top of temporal encoding outputs[^src-gpt-st]:

**Lower level — Hypergraph Capsule Clustering Network**:
- Squash-normalized region embeddings v_{r,t} = squash(V·Γ_{r,t} + c)[^src-gpt-st]
- Dynamic routing (2 iterations, inherited from capsule networks): regions "vote" for cluster center membership via iterative weight updates b_{i,r,t} ← b_{i,r,t} + v_{r,t}^T · squash(s_{i,t})[^src-gpt-st]
- Produces H_S=10 cluster centroids s̄_{i,t}, each representing a semantic region type (e.g., commercial districts, residential areas)[^src-gpt-st]

**Upper level — Cross-Cluster Relation Learning**:
- High-level spatial hypergraph (H_M=16 hyperedges) models migration patterns between clusters[^src-gpt-st]
- Discovers patterns like "residential → commercial" commuting flows by propagating information between cluster centroids across time[^src-gpt-st]
- Refined cluster embeddings propagated back to regions: Ψ_{r,t} = σ(Σ_i c_{i,r,t} · ŝ_{i,t} · W''_r + b''_r + Γ_{r,t})[^src-gpt-st]

The entire encoder stacks 2 blocks of (temporal → spatial) encoding[^src-gpt-st].

### 3. Cluster-Aware Adaptive Mask Strategy

Masks signals progressively from easy (intra-cluster) to hard (cross-cluster)[^src-gpt-st]:

- **Ratio schedule**: Adaptive mask ratio ra = (epoch/E)^γ increases gradually with training[^src-gpt-st]
- **Cluster-based masking**: Pick n cluster categories, mask all elements of n−1 categories entirely, partial-mask the nth — forces cross-cluster reasoning[^src-gpt-st]
- **Total mask ratio**: rt = 0.25 (25% of signals masked — much lower than MAE's 75% for images, reflecting ST data's lower information redundancy)[^src-gpt-st]
- **Bootstrap via proxy MLP**: A two-layer MLP predicts clusters q_{i,r,t} from shallow features, trained with KL divergence against the deep clustering output c̄_{i,r,t} (gradient stopped)[^src-gpt-st]

## Downstream Integration

Pre-trained encoder f outputs ζ = f(X) from unmasked historical data[^src-gpt-st]. The downstream model g receives fused input: H = z·ζ + (1−z)·E, where z = δ(ζ·W_{h,1} + E·W_{h,2} + b_h) — a sigmoid-gated convex combination of pre-trained and original encodings[^src-gpt-st]. The pre-trained encoder is frozen during downstream training[^src-gpt-st].

## Experimental Results

| Dataset | Nodes | Task | Key Improvement (STGCN) |
|---------|-------|------|--------------------------|
| PEMS08 | 170 | Traffic flow | MAE −9.0%, RMSE −9.5% |
| METR-LA | 207 | Traffic speed | MAE −7.3%, RMSE −7.3% |
| NYC Taxi | 266 | Taxi demand | MAE −10.4% |
| NYC Citi Bike | 250 | Bike demand | MAE −8.3% |

All 13 baselines improved on all 4 datasets. Zero counterexamples[^src-gpt-st]. Classic baselines (STGCN, TGCN) benefit substantially more than advanced ones (MSDR, STWA) — suggesting advanced models already encode some of GPT-ST's learned priors[^src-gpt-st].

Vs. STEP (prior ST pre-training): GPT-ST outperforms STEP while using only 12-step input (vs 2-week data) and training 26× faster (12.5s vs 327.8s/epoch)[^src-gpt-st].

| Parameter | Value | Role |
|-----------|-------|------|
| d | 64 | Hidden dimension |

| H_S | 10 | Spatial clusters |

| rt | 0.25 | Total mask ratio |
| λ | 0.1 | KL loss weight |
| L, P | 12, 12 | Input/prediction steps |

## Limitations

- **Task-specific**: Pre-training is dataset-specific — a PEMS08-trained model cannot be reused for NYC Taxi[^src-gpt-st]
- **Fixed cluster count**: H_S=10 assumed uniform across all cities, unlikely in practice[^src-gpt-st]
- **Diminishing returns**: Advanced baselines (MSDR: −3.3% MAE) gain less, suggesting GPT-ST's generic priors overlap with their own learned knowledge[^src-gpt-st]
- **No cross-task pre-training**: Future work needed for a single pre-trained model handling multiple cities and tasks[^src-gpt-st]

## Historical Context

GPT-ST is the first work to successfully adapt the MAE pre-training paradigm from CV ([[mae|MAE]]) to spatio-temporal graph data[^src-gpt-st]. It bridges the gap between: (a) NLP/CV pre-training's universal success and (b) ST prediction's historically end-to-end-only approach. **[[unist|UniST]]** (KDD 2024) extends this paradigm further — from per-dataset MAE pre-training to true cross-dataset one-for-all pre-training, adding memory-based prompt learning for adaptive generalization across cities and domains without fine-tuning model parameters[^src-unist]. The name directly references GPT-GNN (Hu et al., KDD 2020), which pioneered generative pre-training for graph neural networks[^src-gpt-st].
