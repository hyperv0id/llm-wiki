# STReasoner

**STReasoner** is the first TS-LM designed for explicit spatio-temporal reasoning over time series, proposed by Ni et al. (Emory University / Microsoft / Griffith University, arXiv 2026)[^src-streasoner]. Unlike prior time series LMs that prioritize predictive accuracy, STReasoner enables natural-language queries that require linking observations across nodes, time steps, and spatial dependencies[^src-streasoner].

## Architecture

STReasoner processes multimodal inputs by separately encoding time series data and textual inputs[^src-streasoner]:

```
Time Series → Patchify → 5-layer MLP Encoder → TS Embeddings
                                                        ↓
Query + Graph (as text) → Text Tokenizer ─────────→ LLM Backbone (Qwen3) → Reasoning + Answer
```

- **Time Series Encoder**: Lightweight 5-layer MLP. Patches input time series and encodes each patch. Node-associated embeddings are interleaved with text tokens: `[Node₁: ⟨TS₁⟩, Node₂: ⟨TS₂⟩, ..., Graph, Question]`[^src-streasoner]
- **LLM Backbone**: Qwen3 (4B/8B/14B variants). Receives combined text + TS embedding sequence
- **Value-preserving normalization**: Following ChatTS, normalizes features while preserving original numerical information[^src-streasoner]

## Training: Three-Stage Pipeline

### Stage 1: Alignment Pretraining
Uses **ST-Align** (153.7K QA pairs) with basic temporal, spatial, and spatio-temporal questions to align text and TS embeddings[^src-streasoner].

### Stage 2: SFT via Rejection Sampling
Uses **ST-CoT** — CoT annotations generated by Claude-4.5-Sonnet via rejection sampling (5 candidates per question, keep those with correct answers). Provides a strong SFT cold start for reasoning[^src-streasoner].

### Stage 3: S-GRPO
Spatial-Aware GRPO: For each question, generates two groups of responses — with and without spatial structure. The reward function grants bonus only when spatial information improves accuracy[^src-streasoner]:

```
Rᵢ = rᵢˢᵖ + α  if rᵢˢᵖ > β·rᵢⁿˢ
     rᵢˢᵖ        otherwise
```

This contrastive design prevents models from exploiting superficial temporal patterns[^src-streasoner].

## ST-Bench

A four-task benchmark for spatio-temporal reasoning[^src-streasoner]:

| Task | Description | Metric |
|------|------------|--------|
| T1: Etiological | Infer global system-level semantics from dynamics | ACC |
| T2: Entity | Recognize semantic roles of nodes (e.g., demand source vs propagation) | ACC |
| T3: Correlation | Causal reasoning over spatial structure (direct + multi-hop propagation) | ACC |
| T4: In-context Forecasting | Predict future temporal evolution under spatial dependencies | MAE |

## Main Results

| Model | Etiological | Entity | Correlation | Forecasting | Cost |
|-------|:--:|:--:|:--:|:--:|:--:|
| GPT-5.2 (text) | 83.09% | 38.78% | 58.79% | 63.99 | $22.48 |
| GPT-5.2 (image) | 86.47% | 40.54% | 65.08% | 64.70 | $6.69 |
| Claude-4.5-Sonnet (text) | 78.64% | 41.93% | 77.87% | 63.74 | $45.80 |
| Qwen3-8B (zero-shot) | 21.26% | 5.28% | 5.53% | 94.03 | $3.85 |
| **STReasoner-8B** | **95.65%** | **75.71%** | **87.12%** | 65.59 | **$0.27** |

STReasoner achieves 17-135% average improvement over proprietary models at 0.004× cost[^src-streasoner].

**Zero-shot real-world** (CausalRivers): STReasoner **98.82%** vs GPT-5.2 22.32%, Claude 83.18%[^src-streasoner].

## Ablation: Training Stages

| Configuration | Etiological | Entity | Correlation | Forecasting |
|-------|:--:|:--:|:--:|:--:|
| Full (Align+SFT+S-GRPO) | **95.65%** | **75.71%** | **87.12%** | 65.59 |
| Align+SFT+GRPO (no spatial) | 91.79% | 69.60% | 86.12% | 69.96 |
| SFT+S-GRPO (no align) | 91.30% | 67.76% | 83.98% | 69.01 |
| Align+SFT only | 88.41% | 63.32% | 80.97% | 66.65 |
| S-GRPO only | 47.34% | 23.20% | 39.20% | — |

All three stages are essential; removing S-GRPO costs ~3.9% on etiological reasoning[^src-streasoner].

| Model | Spatial? | Reasoning? | Task | Training |

| **STReasoner** | ✓ explicit graph | ✓ multi-step CoT | QA over ST dynamics | Align+SFT+RL |

STReasoner is unique in combining **explicit spatial graph reasoning**, **multi-step CoT**, and **spatial-aware RL**[^src-streasoner].
