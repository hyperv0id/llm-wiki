# Native Sparse Attention（NSA）

DeepSeek-AI、北京大学与华盛顿大学，arXiv:2502.11089v2（2025-02）。论文针对稀疏注意力的两项缺口：理论计算量下降难以转化为延迟下降；多数方法仅能插入推理期，无法端到端训练（§1、§2）[^src-2502-11089-nsa]。

三项贡献。**算法**：每个 query 的前序 KV 由三条支路重映射——块压缩（块长 $l=32$、步长 $d=16$、带块内位置编码的 MLP）、块选择（块长 $l'=64$、取 top-$n=16$ 块，重要性分复用压缩支路的注意力分数，GQA 组内各 head 求和后共享选块结果）、滑动窗口（$w=512$）；三条支路设独立 K/V 与各自的 softmax，经 sigmoid 门控加权求和（式 3–5、§3.3）。**kernel**：按 GQA 组将全部 query head 一次装入 SRAM 并共享同一组稀疏块索引（§3.4），解码期每步读取 $\lfloor (s-l)/d\rfloor+nl'+w$ 个 token（§5.2 文字口径；Table 4 数值按 $\lfloor s/d\rfloor+nl'+w$ 取整）。**训练**：选择分取自压缩支路，无需独立打分网络与辅助损失，稀疏模式在预训练阶段就位（§6.1）。

证据取自 27B 总参 / 3B 激活的 GQA+MoE 骨干，8k 文本上 270B token 预训练（§1 写 260B）。Table 1 平均 0.456 vs Full Attention 0.443，9 项中 7 项更高；Table 2 LongBench 平均 0.469 vs 0.437、Exact-Top 0.423；Table 3 AIME 24 在 16k 生成限制下 0.146 vs 0.092；Figure 6 在 64k 序列上 forward 9.0×、backward 6.0×，Table 4 解码 11.6×。

式（3）（4）用重映射后的 $\tilde K_t,\tilde V_t$ 替换原始 KV 并约束 $N_t\ll t$，不以退化到 full attention 为前提（§3.2）；LongBench 全部稀疏基线按每 query 2560 token 预算对齐，对应 NSA 在 32k 下的平均激活量（§4.3）。

模型规模单一，且 $l,d,l',n,w$ 无消融；对照方法全为推理期稀疏，未与 MoBA 类训练期稀疏同台；token 数在 260B 与 270B 两处口径不一。
