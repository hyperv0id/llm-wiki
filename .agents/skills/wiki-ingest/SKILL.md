# wiki-ingest：单源摄入

用户要求把一份 `raw/` 源文件写进 wiki。页面 schema、frontmatter 字段、引用格式、文体与证据等级在根目录 `AGENTS.md`，动手前先读它；本技能只管流程。

## 硬约束：最小信息原则与反刷分

- `raw/` 不可变，只读。判断源文件有错时在 `wiki/` 写更正页，不改源文件。
- **最小信息原则（源头拒载噪音）**：
  - **非必要不读全文**：禁止一上来通读整篇文本。**References（参考文献）100% 禁读；Appendix（附录）与 Related Work 默认不读**（仅当 Tier 1 论文正文核心公式缺失定义且明写见附录某节时，才按行号定点读该小节；绝不读附录跑分表）。
  - **非必要不核对微观指标**：禁止为了「核对数字」去算两位小数上的微观差距（如 `+0.18 / -0.04`）、禁止验算表格均值算术、禁止主动排查排版/印刷小瑕疵磨洋工。实验只抽定性结论、序关系与关键量级。
- **建页准入门槛**：禁止为常规论文内部的自造模块缩写（如 `AGL`、`ASL`）新建 `source_count: 1` 的独立 `technique` 页。仅当某原语被 $\ge 2$ 篇论文复用/专门对比，或具有独立数学结构（改变复杂度阶数、独立定理或通用求解器）时，才建独立 `technique` / `concept` 页；否则写入 `source-<slug>.md` 并更新领域聚合页矩阵。新建页至少含 1 个 `[^src-*]` 引用。
- **反刷分禁令**：禁止整表照搬论文 Main Table，实验部分（`## 证据`）篇幅不得超过单页 20%。

## 职责与上下文隔离架构（多 Agent 优先 / 单 Agent 漏斗降级）

核心目标是**让「写 Wiki 的上下文」看不见「原论文的海量表格与行号噪音」**。根据当前运行环境（Harness）能力自动选择：

### 模式 A：多 Agent 协作（Harness 支持子 Agent 或 `omp -p` 独立调用时 —— 物理隔离）

1. **Reader Agent（切片脱水员：只读 `raw/` 核心切片，无 `wiki/` 视野）**
   - 先用 `rg -n` 扫描标题行号，只切取 **「Abstract + Intro 末段 + Method + Experiments 的 Setup 与 Ablation」**（跳过 References、Appendix、Related Work 及 Main Table 逐行明细）。
   - 向主 Agent 只回报一张 **$\le 400$ 字的《脱水内参卡》**，严禁传回原始跑分大表或长篇原文：
     1. **人话大义**：不用公式与自造缩写，一句话讲清它面对的具体失效模式与核心巧思。
     2. **去黑话配方与算子 $\Delta$**：用标准算子原语还原前向计算（Tier 1 附关键公式与张量形状变化）；相对最近邻基线，关键改动落在哪一步、有什么新假设或代价？
     3. **Ablation 真相**：消融表里掉点最狠的组件是什么？涨点来自主故事还是工程 trick？
     4. **定性结论与证据缺口**：在主任务上是真超越还是低开销逼近（只给代表性量级，不列细表）？在哪些设置下没赢？漏测了哪类同生态位基线？
2. **Writer Agent（主 Agent / 图谱架构师：禁读 `raw/` 原文，只管 `wiki/`）**
   - **硬隔离：主 Agent 全程禁止打开 `raw/` 原文**，从物理上断绝抄表、算两位小数微差和句中插行号的可能。
   - 仅凭 Reader 回报的《脱水内参卡》+ 读取 `wiki/index.md` 及 2–3 个关联 Wiki 页，执行下方「合入流程」的第 2–10 步。

### 模式 B：单 Agent 渐进漏斗（Harness 无子代理功能时 —— 切片与阶段隔离）

当环境不支持子 Agent 时，单 Agent 必须通过**分阶段读取与显式封存**模拟最小信息原则：

1. **摸边界（不读正文）**：`raw/*.pdf` 先 `pdftotext -layout` 转文本；先用 `rg -n` 找出各章行号，把 References、Appendix、Related Work 划为禁读行区间。
2. **读核心切片并产出《脱水内参卡》**：只按行号读取「Intro 末段 + Method + Ablation」，立即在当前思考步内写出上述 $\le 400$ 字的《脱水内参卡》。
3. **封存原文**：《脱水内参卡》产出后，**后续步骤严禁再调用读取工具回翻 `raw/` 原文查表格或抠细节**，直接切换到图谱合入阶段。

## 合入流程

1. **获取《脱水内参卡》**：按上述模式 A（子 Agent 回报）或模式 B（单 Agent 切片坍缩）拿到脱水结论。
2. **分级分流（Triage）与检索索引**。读 `wiki/index.md` 定位已有相关页面，按三档决定入库深度（用户已指定则遵从）：
   - **Tier 1（基石 / 新算子 / 强理论或颠覆性实证）**：建/更独立机制页，写完整分阶段 `aligned` 维度块与三行实验判词。
   - **Tier 2（常规方法 / 已有积木的新组合）**：**轻量化入库**——只建 `source-<slug>.md`（写清去黑话算子配方与三行实验判词），并在所属领域 `concept` 页对比矩阵里加一行；**不为其内部拼装子模块新建独立 `technique` 页**。
   - **Tier 3（边缘参考 / 弱证据预印本）**：仅建简短 `source-<slug>.md`，在相关页末尾挂一行引用。
3. **跨文关系挂载与既有页更新**：
   - 更新既有页或新建交叉链接时，标明四类有向关系之一，禁止堆砌裸链接：**同构/退化特例**、**瓶颈接力 $\Delta$**、**槽位关系**（同槽位互斥 vs 跨槽位正交）、**实证复现对齐**（新源重跑既有基线出现定性排名反转时回填）。
   - 若涉及的聚合 `concept` / `analysis` 页已关联 $\ge 4$ 篇论文，直接维护其**正交设计决策轴二维矩阵**，禁止继续追加「每篇一段」的流水简介。
   - 发现定性论断冲突按「矛盾处理」执行。
4. **新建页面**：严守「建页准入门槛」；文件名小写、连字符、无空格。Tier 1 模型类页按「数据流与维度变换」写分阶段 `aligned` 块；实验部分严守 `AGENTS.md` 的「三行判词」与 $\le 20\%$ 篇幅上限，**不回原文搬表、不核对微观小数差异**。
5. **写 source-summary**：`wiki/source-<slug>.md`，`type: source-summary`，300–500 字，覆盖人话大义、去黑话算子配方、三行实验判词与核心缺口；`source_count` 与正文实际引用数一致。
6. **可读性与脱水自检**：落盘前按「可读性与脱水自检」过一遍，砍掉句中源码坐标、两位小数报账与 Intro 套话。
7. **更新 `wiki/index.md`**：按 frontmatter `type` 分五段（Sources / Entities / Concepts / Techniques / Analyses），段内字母序，每页仅一条。
8. **更新 frontmatter**：所有被改页面刷新 `last_updated`，重算 `source_count`，调整 `confidence`。
9. **写 `ingest-reports/YYYY-MM-DD-<slug>.md`**（格式见下，含 Tier 定级说明）。
10. **追加 `wiki/log.md`**：

    ```
    ## [YYYY-MM-DD] ingest | {标题}
    {1 段：Tier 等级 + 源解决了什么问题、去黑话机制与定性实验判词；有证据缺口直接写}
    创建的页面：[[page1]], [[page2]]
    更新的页面：[[page3]]（一行改动摘要，source_count 1→2）
    ingest 报告：[[ingest-reports/YYYY-MM-DD-slug|WHY 报告]]
    ```

11. **提交**：dashboard 路径由 `server.py` 自动 commit；手工路径以 `ingest <标题>` 作为 commit message 提交 `raw/`、`wiki/`、`ingest-reports/`。

## 数据流与维度变换（模型类页面必用）

讲模型前向传播时，**禁止用表格罗列张量清单或逐步形状变化**——表格是线性的，表达不了并行支路、汇合过程，也看不出矩阵乘法消掉了哪一维。改用「分阶段计算图块（staged computation blocks）」。

### 1. 维度符号速查

「数据流」小节开头用一到三行交代超参的物理意义，不列中间张量的大表：

> **维度符号**：$N$ 序列长度（token 数）；$d$ 单头通道维；$m$ landmark 数；$k$ 每个专家选中的 token 数。

形状统一记作 $[\text{行}, \text{列}]$，与论文记号一致。论文按单头书写、本页按多头展开时，推断部分标 `[INFERENCE]`。

### 2. 按前向拓扑分阶段

- 一个阶段一个小标题，编号加动词短语：`### Stage 1 · 造 landmark query`。
- 并行支路在同一阶段内用无序列表拆开，各占一个公式块：`**支路 A：共享专家（常开，宽 $m$）**`、`**支路 B：形变专家（稀疏，宽 $k$）**`。支路前先交代它读哪些张量、形状是什么。
- 支路汇合单独成阶段，写清合并方式（拼接、按打分路由、online softmax 合并等）。

### 3. 每个公式块的四要素

```latex
$$\begin{aligned}
S^{kv} &= K^{\top}\tilde{Q}/\sqrt{d} && \text{// } [N, \bcancel{d}]\times[\bcancel{d}, m]\to[N, m]\ \text{——消去 } d\text{，每列是一个 landmark 对全部 } N \text{ 个 key 的打分}\\
\mathcal{I}_i &= \operatorname{Top}_k\!\left(K^{\top}\tilde{q}_i\right) && \text{// } [N, m] \xrightarrow{\text{沿 } N \text{ 维逐列 Top-}k} [k, m]\ \text{——每组 } k \text{ 个 key 下标（取值 } 1..N\text{）}
\end{aligned}$$
```

左侧放张量符号与公式，右侧 `&& \text{// }` 注解必须同时给出**维度变换**和**一句话物理含义**；多行用 `\\` 对齐，注解内部不换行，物理含义用 `\ \text{——}` 接在维度变换之后。

### 4. 维度标注定式

| 操作 | 写法 |
|---|---|
| 矩阵乘法 | 用 `\bcancel{}` 标出被消去的维度：`[N, \bcancel{d}]\times[\bcancel{d}, m]\to[N, m]` |
| 规约 / 池化 / 采样（softmax、Top-$k$、ArgMax、AvgPool） | 带文字的箭头写清沿哪一维操作：`[N, m] \xrightarrow{\text{沿 } N \text{ 维逐列 Top-}k} [k, m]` |
| 索引 / 重排（Gather、ArgSort） | 标明索引张量的形状如何作用于原张量：`[d, N] \xrightarrow{\text{按 } \mathcal{I}\in[mk] \text{ 索引列}} [d, mk]` |

### 5. 表格的用途

表格只承载**跨方法设计决策对照矩阵**或**精简关键数字对比（单篇机制页原则上 $\le 5$ 行）**，既不承载张量形状，也不照搬论文完整 Main Table。已完成分阶段维度流格式的页面可参照 `wiki/mita-attention.md` 的「数据流与维度」小节（其旧版「证据」大表与长勘误清单已废止，不再作为范例）。

## 矛盾处理

新源与既有论断冲突时，按冲突性质三选一，不得静默覆盖：

- **新源更新且证据强**（多源支持、时间更近、方法更直接）：旧论断移入 `## 历史论断`，正文写新论断，注明日期与取代关系。
- **日期相近或新源证据弱**（单一源、 preprint、口径不明）：正文建 `## 争议`，并列两种论断，页面 `status: disputed`，写清待解决点。
- **新源明确反驳旧源**：旧 source-summary 页设 `status: superseded` 与 `superseded_by: [[新页]]`。

三种情况都追加 `wiki/log.md`：

```
## [YYYY-MM-DD] contradiction | {页面} | {情况 1/2/3}
{旧论断} vs {新论断}。解决方案：{所选情况}。
```

## 可读性与脱水自检（必选）

废除「锁死所有符号/表号并硬砍连接词」的电报式字数压缩。页面落盘前必须执行以下 4 项可读性与脱水自检：

1. **实验篇幅与微观算术检查**：`## 证据` 是否超过全文 20%？是否出现了 $>5$ 行的原表搬运、两位小数的逐行加减法报账（如 `+0.2 / -0.1`）或均值验算？若是，立即删表/删算术，改写为 3 条定性实验判词（定位与主结论 / Ablation 归因 / 证据缺口与负结果）。
2. **首段人话与坐标剥离检查**：页面及每个核心小节的第一段是否混入了下标公式碎片或句中源码坐标 `（§3.2，式 7，Alg 1 行 9）`？若是，先用通顺人话讲清大义，公式集中进 `aligned` 块，坐标统一退至句末或表格出处列。
3. **去黑话检查**：是否直接用论文自造模块缩写解释机制而未还原为标准算子？是否抄了 Intro 的通配符套话（如「现有方法难以捕获复杂动态关系」）？若是，重写。
4. **建页准入检查**：Tier 2 论文是否违规新建了 `source_count: 1` 的缩写词 `technique` 页？若是，合并回 `source-summary` 与领域矩阵。

## WHY 报告格式

```markdown
# Ingest 报告：{source_name}

- **分级**：Tier 1 / Tier 2 / Tier 3（一句话定级理由）

## 创建
- wiki/page.md — WHY：一行理由

## 修改
- wiki/page.md — WHY：一行理由

## 新建交叉链接（标明关系类型）
- [[a]] ↔ [[b]]（同构 / 瓶颈接力 Δ / 同槽位互斥 / 跨槽位正交 / 复现对齐）
```

## 完成判据

- 严格执行最小信息原则：未通读 References / Appendix 等非必要章节，未做两位小数微观差值计算或均值验算。
- 已按 Tier 1/2/3 分流，未为常规拼装模块违规新建 `source_count: 1` 的缩写词 `technique` 页。
- 每个页面与核心小节首段均为人话直觉，无句中源码坐标干扰；Tier 1 模型类页前向数据流为分阶段 `aligned` 块。
- `## 证据` 篇幅 $\le 20\%$，以三行实验判词呈现，无整表照抄与逐行报账。
- 跨文链接均标明具体关系类型；关联 $\ge 4$ 篇论文的聚合页维护二维矩阵而非段落报菜名。
- `wiki/index.md`、`wiki/log.md`、`ingest-reports/`、被改页面 frontmatter 均已更新，WHY 报告与实际文件一一对应。
