## 逐页判断后未修改的候选页

- `wiki/quest-attention.md` — 主题是 key 归一化与注意力锐度，query 为标准注意力查询，与 learned query 解码无实质关联，强链会误导图谱。
- `wiki/pdformer.md` — DFT 是 k-Shape 模式记忆 + 相似度加权的记忆/匹配机制，不是 learned query 解码；不补引。
- `wiki/traffic-forecasting.md` — DETR 非交通预测方法，页面按方法谱系组织，插入会破坏分类口径。
- `wiki/graph-learning-as-self-attention.md`、`wiki/algorithm-unrolling.md` — 讨论图学习模块与 Q/K/V 的参数等价性/优化展开，与 DETR 无机制交集。
- `wiki/masked-generative-modeling.md` — 迭代掩码并行解码与 DETR 的一次性并行集合解码是不同范式，不强行互链。
- `wiki/query-aggregate-attention.md` — Q 来自时间 token 而非可学习参数；仅从 detr/object-queries 侧单向链接，不动该页。
