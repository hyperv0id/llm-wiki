## Benamou Brenier算法

### Brief

是一种连续数值方法，将最优传输问题转化为一个容易处理的 d+1 维凸变分问题。我们将会用Wasserstein测地线的理论描述它（相比于找到映射，这个方法是找到测地曲线 μ_t）。

另外两个经典的连续方法是：

- Angenent-Hacker-Tannenbaum：基于最优传输映射应该是一个梯度的事实，移除非梯度项来减少能量；
- Loeper-Rapetti：基于Monger-Ampere方程的解析(resolution)。

这两种方法都需要光滑和非消逝(non-vanishing)的密度，以及特殊的域来处理边界数据(一个长方形，或者更好的，一个环面)。Monge-Ampère方程在更一般的域上的解决问题更加微妙，最近已经被解决了。

## Benamou Brenier构想和它的数值应用

5.3和5.4节的结果允许我们将对应于代价为|x-y|^p的优化问题用一种聪明的方式重写，将它转化成一种凸优化问题。实际上就是：

- 寻找代价为|x-y|^p的OT等价于寻找W_p空间中的常速测地线，因为从最优计划中，我们可以重建测地线；从测地线中(通过它们的速度场)，重构OT也是有可能的；
- 常速测地线可以通过最小化∫_0^1|μ'|(t)^p dt来找到；
- 在Wasserstein空间的情况下，我们有|μ'|(t)^p = ∫_Ω|v_t|^p dμ_t，其中v是一个和μ一起求解连续方程的速度场。这个场不是唯一的，但是度量导数|μ'|(t)等于所有可能的场的L^p范数的最小值。

作为这些考虑的结果，对于p>1，解决动能最小问题：

min {∫_0^1 ∫_Ω |v_t|^p dϱ_t dt : ∂_t ϱ_t + ∇·(v_t ϱ_t) = 0, ϱ_0 = μ, ϱ_1 = ν}

选择了连接μ到ν的常速测地线，因此允许找到两个测度间的最优传输。

另一方面，变量(ϱ_t, v_t)的这个最小化问题有非线性约束（由于乘积v_t ϱ_t），而且泛函是非凸的（由于(t,x) ↦ t|x|^p是非凸的）。但是，我们可以知道，结合5.3.1节的工具，将它转化为凸问题是可能的。

为此，转换变量就足够了，从(ϱ_t, v_t)到(ϱ_t, E_t)，其中E_t = v_t ϱ_t，在时空(space-time)中使用泛函B_p。回忆B_p(ϱ, E) := ∫ f_p(ϱ, E)，其中f_p : R × R^d → R ∪ {+∞}，定义在引理5.17中。

```
f_p(t, x) := sup_{(a,b) ∈ K_q} (a t + b·x) = {
    1/p · |x|^p / t^{p-1}    if t > 0,
    0                         if t = 0, x = 0,
    +∞                        if t = 0, x ≠ 0, or t < 0
}
```

其中 K_q := {(a, b) ∈ R × R^d : a + 1/q · |b|^q ≤ 0}。问题变为：

**问题6.1** 求解

(B_p P)  min {B_p(ϱ, E) : ∂_t ϱ_t + ∇·E_t = 0, ϱ_0 = μ, ϱ_1 = ν}.

我们可以这样写：B_p(ϱ, E) = ∫_0^1 B_p(ϱ_t, E_t) dt = ∫_0^1 ∫_Ω f_p(ϱ_t(x), E_t(x)) dx dt。

我们还想要强调，由∂_t ϱ_t + ∇·E_t = 0, ϱ_0 = μ, ϱ_1 = ν给出的约束实际上是时空(space-time)中的发散约束 (考虑向量 (ϱ, E): [0,1] × Ω → R^{d+1})。空间边界约束已经是无通量类型(no-flux type)，ϱ的初始值和终值提供了边界{0}×Ω和{1}×Ω上的非齐次Neumann数据。确实，整个约束可以理解为 ∇_{t,x}·(ϱ, E) = δ_0 ⊗ μ - δ_1 ⊗ ν（注意，使用(t, x)的导数的观点会在本节再次出现）。我们将最小化的泛函是一个1维齐次泛函，这样(B_p P)变成了我们在4.2节所见的Beckmannn问题的动态版本（在时空上）。这就是如果我们应用[196]中提出的成本|x-y|^p降低而得到的问题，这将其转化为时空上的1齐次运输成本。

现在，约束是线性的，而泛函是凸的。然而，泛函（以及函数f_p）是凸的，但不是很多，因为正如我们所说的，是1-齐次的。特别的，它不是严格凸且是不可微的。这降低了任一梯度下降算法解决问题的效率，但可以使用一些改进的方法。

在[34]中，作者在此基础上提出了一种数值方法，基于变量的凸性变化，对偶性以及所谓的"增强拉格朗日(augmented Lagrangian)"。

### 鞍点(saddle point)，Uzawa和增广Lagrangian

假设我们需要最小化一个凸函数f: R^N → R，满足k个线性等式约束Ax = b (其中b ∈ R^k，以及A ∈ M^{k×N})。这个问题等价于：

min_{x∈R^N} f(x) + sup_{λ∈R^k} λ·(Ax - b).

这给出了一个具有Lagrangian函数L(x, λ) := f(x) + λ·(Ax - b)的min-max问题。如果我们相信对偶，对f在约束下找到一个最小化子等价于找到一个g(λ) := inf_{x∈R^N} f(x) + λ·(Ax - b)的最大化子。这也等价于为L找到鞍点。

在λ处的最大化是更容易的，因为问题是非约束的：可以用一个梯度算法(见Box 6.8)。我们只需要计算∇g(λ)，通过∇g(λ) = A x(λ) - b，这也是比较容易得到的，其中x(λ)是(希望唯一) x ↦ f(x) + λ·(Ax - b)的最小化子。

我们从这个想法中获得的算法，叫做Uzawa algorithm，如下：给定(x_k, λ_k)，设x_{k+1} := x(λ_k)以及λ_{k+1} = λ_k + τ ∇g(λ_k) = λ_k + τ(A x_{k+1} - b)，对于一个给定的小的τ，点x_k的序列收敛，在合理的假设下，收敛到原始问题的最小化子。

一个使得点x(λ)的计算更容易以及加速收敛的替代的想法如下：相比于使用Lagrangian L(x, λ)，使用以下变体 — L̃(x, λ) := L(x, λ) + τ̃/2 |Ax - b|^2，对于一个τ̃的给定值。成为L̃和L的一个鞍点的条件分别是：

for L̃: { ∇f(x) + A^t λ + τ̃(Ax - b) = 0, Ax - b = 0 }
for L: { ∇f(x) + A^t λ = 0, Ax - b = 0 }

因此，L̃和L的鞍点是相同的，但是使用L̃使得问题更凸，在x点更容易处理。然后，在g̃(λ) := inf_x f(x) + λ·(Ax - b) + τ̃/2 |Ax - b|^2上使用相同的梯度算法，使用步长τ。取τ = τ̃，迭代以下算法：

{ x_{k+1} = argmin f(x) + λ_k·(Ax - b) + τ/2 |Ax - b|^2
  λ_{k+1} = λ_k + τ(A x_{k+1} - b) }

### 算法步骤

首先，我们用弱形式来写出约束（根据（4.3））。这意味着我们想求解

min_{ϱ, E} B_p(ϱ, E) + sup_ϕ (-∫_0^1 ∫_Ω ((∂_t ϕ) ϱ_t + ∇ϕ·E_t) + G(ϕ)),

其中我们设

G(ϕ) := ∫_Ω ϕ(1, x) dν(x) - ∫_Ω ϕ(0, x) dμ(x)。

#### 与Hamilton-Jacobi方程的关系

考虑最简单的情形p=2。在这种情况下，我们可以将问题写做：

min_{(E, ϱ): ϱ ≥ 0} ∫_0^1 ∫_Ω |E|^2/(2ϱ) + sup_ϕ -∫_0^1 ∫_Ω ((∂_t ϕ) ϱ + ∇ϕ·E) + G(ϕ),

其中，我们用B_2的积分形式来表达它，在绝对连续测度下是有效的，其中ϱ ≥ 0 (如果ϱ=0，我们必须使得E=0，为了得到有限能量)。

如果我们交换inf和sup，我们将得到下面的问题：

sup_ϕ G(ϕ) + inf_{(E, ϱ): ϱ ≥ 0} ∫_0^1 ∫_Ω (|E|^2/(2ϱ) - (∂_t ϕ) ϱ - ∇ϕ·E).

我们可以首先计算出最优E, 对于固定的ϱ和ϕ, 因此得到E = ϱ ∇ϕ。问题变为

sup_ϕ G(ϕ) + inf_{ϱ ≥ 0} ∫_0^1 ∫_Ω (-(∂_t ϕ) ϱ - 1/2 |∇ϕ|^2 ϱ).

下确界有限(因此消逝)的条件是∂_t ϕ + 1/2|∇ϕ|^2 ≤ 0，在最优条件下，我们必须有相等，在{ϱ>0}上。这就给出了Hamilton-Jacobi等式：

∂_t ϕ + 1/2 |∇ϕ|^2 = 0   ϱ-a.e.

而且，从最优ϕ中，我们可以使用ψ(x) := ϕ(1, x)和φ(x) := -ϕ(0, x)来恢复Kantorovich势。

在这个变分问题中，B_p可能会表示成sup，因此我们得到：

min_{ϱ, E} sup_{(a,b)∈K_q, ϕ} ∫_0^1 ∫_Ω (a(t,x) dϱ + b(t,x)·dE - ∂_t ϕ dϱ - ∇ϕ·dE) + G(ϕ).

### 增强拉格朗日

令m = (ϱ, E)。这里m: [0,1] × Ω → R^{d+1}是一个定义在d+1维空间的d+1维向量场。类似的，我们设ξ = (a, b)。我们也用∇_{t,x} ϕ表示ϕ的时空梯度，即∇_{t,x} ϕ = (∂_t ϕ, ∇ϕ)。

问题被重写为：

min_m sup_{ξ, ϕ: ξ ∈ K_q} ⟨ξ - ∇_{t,x} ϕ, m⟩ + G(ϕ).

这就是使用增强拉格朗日方法的想法。实际上，上面的问题让人想起了拉格朗日，但是是以相反的方式。我们必须认为对偶变量是m，原始变量是(ξ, ϕ)。函数f(ξ, ϕ)包括项G(ϕ)和约束ξ ∈ K_q，还有一个等式约束ξ = ∇_{t,x} ϕ。

因此，我们寻找以下问题的解：

min_m sup_{ξ, ϕ: ξ ∈ K_q} ⟨ξ - ∇_{t,x} ϕ, m⟩ + G(ϕ) - τ/2 |ξ - ∇_{t,x} ϕ|^2

#### 迭代算法

找寻最优的算法需要做以下工作：产生一个序列m_k，对于每个k，寻找最优(ξ_k, ϕ_k)。算法包括以下三个迭代步骤。假设我们有一个三元组(m_k, ξ_k, ϕ_k)：

1. **更新ϕ**：在给定m_k和ξ_k的情况下，通过求解下式，找到最优的φ_{k+1}：

   max_φ -⟨∇_{t,x} φ, m_k⟩ + G(φ) - τ/2 ‖ξ_k - ∇_{t,x} φ‖^2

   这归结为最小化关于∇_{t,x} φ的二次问题。解可以通过求解Laplace方程τ Δ_{t,x} φ = ∇·(τ ξ_k - m_k)来找到，以及一个时空Laplacian算子和Neumann边界条件。这些条件关于空间是齐次的，由于G的存在，在t=0和t=1时刻是非齐次的。大多数Laplace求解器可以在O(n log n)的倍数复杂度内找到解，这里n是离散化的点的个数。

2. **更新ξ**：给定m_k和φ_{k+1}的情况下，通过求解下式，找到最优的ξ_{k+1}：

   max_{ξ ∈ K_q} ⟨ξ, m_k⟩ - τ/2 |ξ - ∇_{t,x} φ_{k+1}|^2

   通过展开平方项，我们看到这个问题等价于计算∇_{t,x} φ_{k+1} + (1/τ)m_k的投影，并且没有梯度出现在这一优化步骤里。优化算法逐点执行，通过对每个(t, x)选取点ξ = (a, b)，这个点是在凸集K_q中最接近∇_{t,x} φ_{k+1}(t,x) + (1/τ)m_k(t,x)的点。如果我们有一个在R^{n+1}中的投影算法，并且此投影算法需要一个常数的操作，则这一逐点的步骤的代价为O(N)。

3. **更新m**：通过设置m_{k+1} ← m_k - τ(ξ_{k+1} - ∇_{t,x} φ_{k+1})来更新m。

这个算法在每个迭代过程中共需要O(N log N)次操作（N是由时空中的离散化给定的）。它可以被证明是收敛的。

### 优点

与其他算法相比，Benamou-Brenier方法有一些重要的优点：

1. 到目前为止，它几乎是唯一一个毫不费力地处理密度消失的方法，而且对它们的支集也不需要特殊的假设；

2. 不需要特定的二次代价：我们用幂次代价c(x,y)=|x-y|^p提出它，但是它也可以适用于其他凸代价函数h(x-y)，以及所有拉格朗日作用产生的代价函数；它可以包含取决于位置和时间的成本，适用于黎曼流形；

3. 它可能适合考虑密度ϱ上的凸约束(例如，下界或上界)；

4. 它可以处理不同的"动态"问题，在密度或速度上添加惩罚，就像在平均场博弈论中发生的那样(见章节8.4.4)，并且已经被利用，例如，在[35]中；

5. 它可以处理多个种群，具有可能的相互作用行为。
